The matching statistics of string $q$ with respect to string $r$ is
the array of lengths of longest substring in $q$ that match somewhere
in $r$ \cite{cha94:sub}. In our program Fur, we implemented something
similar, match lengths as computed with Algorithm~\ref{alg:ml}. The
purpose of this document is to compare the match lengths of Fur with
the matching statistics. For this purpose we write the program
\ty{mast}, which takes as input a query sequence, $q$, and a reference
sequence, $r$, and prints the match lengths and matching statistics of
$q$ with respect to $r$.
